# Cortex-Drive: The Explainable Memory Platform

Cortex-Drive is a specialized AI platform designed to transform fragmented information into a high-fidelity **Enterprise Context Graph**. It moves beyond simple text search, organizing knowledge by **meaning and relationship** rather than just source location.

## 🚀 Vision
In the age of generative AI, the bottleneck is no longer "generating" content, but "anchoring" it in truth. Cortex-Drive provides the structured memory layer that allows AI agents to reason with absolute context, governance, and explainability.

## 🛠 Core Features
- **GraphRAG Architecture**: Combines the power of Neo4j Knowledge Graphs with Vector Search (PGVector) for 100% grounded retrieval.
- **Explainable AI Reasoning**: Every response from Cortex-Drive can be traced back to exact nodes and relationships in the graph.
- **Enterprise-Grade Multitenancy**: Built for scale with Clerk-integrated org isolation and secure RAG guardrails.
- **Bento Detail Visualization**: A premium UI experience that allows users to "double-click" into the professional context of any entity.
